# 功能讲解 · 打牌记分器（样例）

> 按手册 §11 的七段格式写的真实样例。以后每次变更结束，照这个结构追加一段。

## 功能清单

1. **加玩家** —— 输入名字加入牌局，最多 8 人，重名不加。
2. **记一局** —— 每人填本局得分（可为负），点一下存成一局。
3. **排行榜** —— 按总分从高到低，带名次。
4. **统计摘要** —— 人数、局数、领先者。
5. **持久化** —— 刷新后数据还在。

---

## 计分（本文讲这一块）

### 1. 功能一句话

把每局每个人的得分按人累加，算出总分，再按总分排出名次。

### 2. 入口

- 写入：`#new-round` 点击（记一局）。
- 变化：玩家标签上的 × （删人）。
- 读取：每次 `render()` 都会重新算一遍，排行榜和摘要都从它取数。

### 3. 数据怎么走

1. 点 `#new-round` → 从 `draft` 读每个输入框 → 空值转 0 → 凑成 `{p1:10, p2:5, p3:-3}`
2. 交给 `addRound()` 校验 → `state.rounds.push()` → `save()` → `render()`
3. `render()` 调 `getRanking()`
4. `getRanking()` 调 `sortedPlayers()`，后者对每个玩家调 `totalOf()` 求和
5. `render()` 把 `rank` 写进 `.rank-item` 的 `data-rank`，把 `total` 写进文字

### 4. 关键代码

```js
function totalOf(pid) {
  var sum = 0;
  for (var i = 0; i < state.rounds.length; i++) {
    var v = state.rounds[i][pid];
    if (typeof v === 'number') sum += v;   // ← 为什么要有这一句
  }
  return sum;
}
```

- `typeof v === 'number'` 不是多余：玩家可能第 3 局才加入，前两局的对象里没有他的 key，`undefined` 一旦加进 `sum` 就变 `NaN`，整张排行榜全废。
- 负数不需要特殊分支，`-3` 就是普通数字。

```js
return state.players.slice().sort(function (a, b) {
  return (totalOf(b.id) - totalOf(a.id)) || (a.seq - b.seq);
});
```

- `slice()` 先复制：`sort` 原地排序，直接排 `state.players` 会把玩家列表的顺序也改掉。
- `||` 是第二段：总分相同（差值 0，假值）时按 `seq`（加入先后）排，否则同分的人刷新后名次会跳。
- 代价：比较器里每次重算总分，最坏 O(n²×局数)。8 人几十局无所谓；几千条就该先算一张总分表再排。

### 5. 取舍与代价

- **总分不缓存**：每次现算。代价是 O(人数×局数)，好处是删人、删局之后绝不会有脏数据——这也是变更里「删除后立即重算」不用写一行重算代码的原因。
- **按局存，不按人存**：`rounds` 是数组，每个元素是「这一局所有人的分」。如果反过来存 `player.scores = [10, -2]`，删第 1 局就得挨个去每个人身上删下标 0，删错一次全乱；现在删一局就是 `splice` 一行，所有人天然对齐。
- **排序和名次分开**：`sortedPlayers()` 只管排，`getRanking()` 再加 `rank`。变更要改成并列跳号时只动后者。

### 6. 边界

- **0 局**：所有人总分 0 → 按加入先后排，名次 1..n，领先者是第一个加入的人。
- **中途加入**：早期局里没有他的 key，`totalOf` 跳过，只算加入之后的局。
- **负分 / 小数**：`Number('-3')` 是 -3，`isFinite` 通过，累加和排序都正常。
- **删到只剩 1 人**：排行榜仍能出，摘要的领先者就是他自己。
- **接口非法输入**：`addRound` 里缺玩家、字符串、`NaN` 一律返回 `null`，不写进 `rounds`。

### 7. 一句话答辩版

> 分数按局存，每人总分现算不缓存。`totalOf` 做单列求和，`sortedPlayers` 按总分降序、同分按加入先后，`getRanking` 在排序结果上加序号，摘要直接复用排序的第一个。所以删人删局只改数据，重画就自动对——变更里「立即重算」那条我没写一行重算代码。

## 术语表

| 词 | 一句话 |
| --- | --- |
| `state` | 唯一的状态对象：`players` / `rounds` / `seq` |
| `draft` | 记分格里还没提交的输入，不进 `state`、不触发渲染 |
| `rounds` | 数组，一个元素是一局，下标 +1 就是局号 |
| `seq` | 玩家编号计数器，同时用来给同分的人排先后 |
| `render()` | 全量重画四个区块，所有界面都从 `state` 现算 |
| 钩子 | 题面契约表要求的 id / class / `data-*` / 全局函数，机器靠它找页面 |
