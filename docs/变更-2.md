# 变更 2（T0+33 才打开）

建立在变更 1 的成果上。

## 1. 名次并列

排行榜同分并列：两人并列第一则都 `rank = 1`，**下一个是 `rank = 3`（跳号）**，以此类推。

- `getRanking()` 每项的 `rank` 和 `.rank-item` 的 `data-rank` 都要是并列后的值；
- 顺序保持稳定：同分时按加入先后排。

## 2. 统计扩展

`#summary` 改为下面这个口径（数字和名字要对得上）：

`共 N 人 · M 局 · 领先者 X（Y 分）· 最大分差 Z`

最大分差 = 最高总分 − 最低总分；0 局或只有 1 人时为 0。
`getStats()` 增加 `spread` 字段。

## 3. 导出

新增 `#export-btn`，点击导出 CSV：

- 表头：`局号,玩家1,玩家2,…,合计`（玩家按加入先后）
- 每局一行，最后一行总分
- 文件名 `scores.csv`
- 必须本地生成（Blob），不能联网
