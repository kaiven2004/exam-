# 变更 1（T0+18 才打开）

需求方提了三点。只做增量，不要重写整份文件。

## 1. 局明细

新增 `#round-list`：每一局一项 `.round-item`，带 `data-round="局号"`，文本里展示该局每个玩家的得分，以及这一局的合计。

**最新一局排最前。**

## 2. 删除某一局

每项里加一个删除按钮。删除后：

- 所有总分、排名、`#summary` 立即重算；
- 局号顺延重排——删掉第 2 局后，原来的第 3 局变成第 2 局，`data-round` 同步；
- 全部删完后 `#round-list` 为空，页面不报错。

## 3. `getStats()` 增加字段

`bestRound`: `{ round, total }`，表示**单局所有玩家得分合计最高**的那一局的局号和合计。并列时取局号小的；没有局时返回 `null`。
