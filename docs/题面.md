## 场景

几个朋友打牌，需要一个记分器：先把人加进来，每打完一局录入各人得分，随时看总分排名。

## 功能需求

1. **加玩家** — 输入名字（1~8 个字）添加到玩家列表，最多 8 人。空名、重名不添加。
2. **玩家列表** — `#player-list` 里每人一项 `.player-item`，显示名字，可删除。删除后总分和排名立即重算。
3. **记一局** — `#score-table` 为每个玩家提供一格数字输入（**可为负数**）。点 `#new-round` 把当前输入记为「一局」，然后清空输入格。
4. **排行榜** — `#ranking` 按**总分从高到低**排列，每人一项 `.rank-item`，显示名次、名字、总分。
5. **统计** — `#summary` 的文本里要同时出现：玩家数、局数、总分最高者的名字。
6. **持久化** — 刷新页面后玩家、局、分数都还在。
7. **空态** — 一个玩家都没有时显示 `#empty`，有玩家时隐藏。

## 全局函数

```js
window.addPlayer(name)     // 返回新玩家 id（字符串）；空名 / 重名 / 已满 8 人 → null
window.addRound(scores)    // scores 形如 { [playerId]: 分数 }；记一局，返回局号（从 1 开始）；非法 → null
window.getRanking()        // 数组，按总分降序，每项 { id, name, total, rank }；rank 从 1 开始且连续
window.getStats()          // { players, rounds, totalPoints, leader }
```

- `scores` 里缺任何一个当前玩家 → `null`
- 分数必须是数字（可为负），`NaN` / 字符串数字以外的值 → `null`
- `totalPoints` = 所有局所有玩家得分之和
- `leader` = 总分最高者的名字；没有玩家时 `null`
